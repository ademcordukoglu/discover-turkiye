# Discover Türkiye

A single-page visual travel guide to 19 destinations across Türkiye's seven regions,
in **English, Deutsch, Русский and العربية** — with full right-to-left layout for Arabic.

No build step, no dependencies, no JavaScript framework: one `index.html` plus photos.

**Live:** https://ademcordukoglu.github.io/discover-turkiye/

Photos from [Wikimedia Commons](https://commons.wikimedia.org), under CC licenses.
